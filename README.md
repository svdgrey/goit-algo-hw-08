# Домашнє завдання №8. Дерева та купи

Реалізація трьох завдань до тем 7 та 8 курсу **Basic Algorithms and Data Structures 2.0**.

## Завдання 1. Пошук мінімального значення

Реалізовано функцію `find_min()`, яка знаходить найменше значення у двійковому дереві пошуку (BST) або AVL-дереві.

Для порівняння обидва дерева створюються з однакового набору випадкових унікальних чисел. 
Програма виводить структури дерев, мінімальні значення та кількість відвіданих вузлів.

**Запуск:**

```bash
python hw01.py
```

## Завдання 2. Сума значень дерева

Реалізовано рекурсивну функцію `tree_sum()`, яка обчислює суму значень усіх вузлів BST або AVL-дерева.
Для обох дерев використовуються однакові числа, тому результати мають збігатися.

**Запуск:**

```bash
python hw02.py
```

## Завдання 3. Об'єднання мережевих кабелів

Реалізовано алгоритм пошуку мінімальних загальних витрат на об'єднання кабелів різної довжини за допомогою мінімальної купи (`heapq`).

На кожному кроці програма обирає два найкоротші кабелі, об'єднує їх та повертає отриманий кабель до купи. Виводяться проміжні результати й накопичені витрати.

**Запуск:**

```bash
python hw03.py
```

## Файли проєкту

- `hw01.py` - пошук мінімального значення дерева.
- `hw02.py` - обчислення суми значень дерева.
- `hw03.py` - мінімізація витрат на об'єднання кабелів.
- `bst.py` - реалізація двійкового дерева пошуку.
- `avl.py` - реалізація AVL-дерева.
- `utils.py` - генерація тестових даних і форматування дерев.
